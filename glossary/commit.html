用語集

コミット (Commit)

ある時点での変更を 「セーブポイント」として記録する操作。または、その記録そのもの。 ゲームのセーブと同じく、いつでもその時点に戻ることができます。

コミットに含まれる情報

1つのコミットには、次のような情報が記録されます。

  • コミットID — 一意な識別子 (例: f1e2d3c4b5a6...)
  • 作者と日時 — STEP 03 で設定した名前とメールアドレス
  • コミットメッセージ — 何を変更したかの説明
  • 変更内容 — 直前のコミットからの差分
  • 親コミット — 直前のコミットへのリンク (これがあるから「履歴」になる)

コミットの作り方

  1. ファイルを編集する
  2. git add で ステージング に置く
  3. git commit -m "メッセージ" でコミット
