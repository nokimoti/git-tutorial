用語集

チェックアウト (Checkout)

Git の古くからあるコマンド git checkout のこと。「ブランチ切替」と「ファイル復元」の両方 をこの1コマンドが担っていて、初心者には混乱しやすいため、現在は2つに分割した git switch と git restore の使用が推奨されています。

新旧コマンドの対応

古い書き方新しい書き方意味
git checkout maingit switch mainブランチを切り替え
git checkout -b featuregit switch -c feature作成して切り替え
git checkout -- file.txtgit restore file.txtファイルの変更を破棄
git checkout HEAD file.txtgit restore --source=HEAD file.txtHEADの状態に戻す

古い記事ではこの呼び方が多い

Web 上の Git 記事や書籍は checkout を使ったものが大半です。意味がわからないときは 「これは switch か restore のどっちのことかな」 と考えると整理がつきます。

git checkout は今でも動きます。新規に学ぶなら switch / restore が分かりやすい、という話。
