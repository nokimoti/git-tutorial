プル (Pull)

リモート リポジトリの変更を、ローカルに ダウンロードして取り込む 操作。

使い方

git pull

中身は2つの動きの組み合わせ

git pull は、実は次の2つを順番に実行しているだけです。

  1. フェッチ — リモートの最新情報をダウンロード
  2. マージ — ダウンロードした内容を現在のブランチに合流

注意点

ローカルでコミットした変更とリモートの変更が衝突すると、コンフリクト が起きる可能性があります。 慌てず手作業で解決しましょう。

関連用語

  • プッシュ — 逆方向の操作
  • フェッチ — ダウンロードだけ行う
