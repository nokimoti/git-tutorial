コマンド一覧

よく使う Git コマンドのチートシートです。各コマンドの詳しい使い方や前提知識は、関連する STEP のリンクから参照してください。

コマンド中の <...> は自分の値に置き換える部分です。

初期設定

コマンド意味関連
git config --global user.name "名前"ユーザー名を設定 (1度きり)STEP 03
git config --global user.email "メール"メールアドレスを設定 (1度きり)STEP 03
git config --global init.defaultBranch main新規リポジトリの初期ブランチ名を main にSTEP 03
git config --list現在の設定を一覧表示—
git --versionインストール済みの Git バージョンを確認STEP 02

リポジトリの作成・取得

コマンド意味関連
git initカレントフォルダをリポジトリ化STEP 04
git clone <URL>リモートリポジトリを丸ごとコピーSTEP 17
git clone <URL> <フォルダ名>名前を指定してクローンSTEP 17

状態の確認

コマンド意味関連
git status変更・ステージング・ブランチの状況を表示STEP 06
git status -s短縮形式で表示 (慣れたら便利)—
git diff未ステージの変更内容を表示STEP 06
git diff --stagedステージ済みの変更内容を表示STEP 06
git diff <コミット1> <コミット2>2つのコミット間の差分を表示—

ステージング・コミット

コマンド意味関連
git add <ファイル>ファイルをステージングに追加STEP 05
git add .カレント以下の全変更をステージングSTEP 05
git add -A削除も含めて全変更をステージング—
git add -p変更を分割して対話的に選んでステージング—
git commit -m "メッセージ"ステージ済みの内容をコミットSTEP 05
git commit -am "メッセージ"追跡中ファイルの変更を add+commit を一発で—
git commit --amend直前のコミットを書き換えSTEP 08

履歴を見る

コマンド意味関連
git logコミット履歴を新しい順に表示STEP 07
git log --oneline1コミット1行のコンパクト表示STEP 07
git log --oneline --graph --allブランチを含むグラフ表示STEP 07
git log -p各コミットの差分も表示—
git log -n 5直近5件だけ表示—
git show <コミットID>特定コミットの内容と差分を表示—
git blame <ファイル>各行を最後に編集したコミットを表示—

変更を取り消す

コマンド意味関連
git restore <ファイル>未ステージの変更を破棄STEP 08
git restore --staged <ファイル>ステージングを解除 (編集は保持)STEP 08
git revert <コミットID>指定コミットを打ち消す新コミットを作る (履歴は残る)STEP 08
git reset --soft HEAD~1直前のコミットだけ取り消し (変更とステージは残す)用語
git reset HEAD~1直前のコミットを取り消し、ステージも解除 (デフォルト=mixed)用語
git reset --hard HEAD~1変更ごと 直前のコミットを破棄 (危険)用語

ブランチ操作

コマンド意味関連
git branchローカルブランチ一覧STEP 09
git branch -aリモート含む全ブランチ一覧—
git branch <名前>ブランチを作成 (移動はしない)STEP 09
git switch <名前>ブランチに切り替えSTEP 10
git switch -c <名前>作成と同時に切り替え (よく使う)STEP 09
git switch -直前のブランチに戻る—
git branch -d <名前>マージ済みブランチを削除STEP 11
git branch -D <名前>強制削除 (未マージでも消す)—
git branch -m <旧> <新>ブランチ名を変更—
git merge <ブランチ>指定ブランチを現ブランチに統合STEP 11
git merge --abort進行中のマージを中止STEP 12
git rebase <ブランチ>履歴を別ブランチの上に積み直す用語

タグ

コマンド意味関連
git tagタグ一覧STEP 13
git tag <名前>軽量タグを現在のコミットに付けるSTEP 13
git tag -a <名前> -m "メッセージ"注釈付きタグを作成 (リリース推奨)STEP 13
git tag -d <名前>タグを削除STEP 13
git push origin <タグ>タグを1つリモートに送るSTEP 13
git push --tags全タグをまとめてリモートに送る—

リモート操作

コマンド意味関連
git remote -v登録済みリモート一覧STEP 15
git remote add origin <URL>リモートを origin として追加STEP 15
git remote set-url origin <URL>リモートの URL を変更—
git remote rename <旧> <新>リモートの呼び名を変更—
git remote remove <名前>リモートを登録解除—
git push現ブランチをリモートに送信STEP 16
git push -u origin <ブランチ>初回プッシュ (上流追跡を設定)STEP 16
git push origin --delete <ブランチ>リモートのブランチを削除—
git pullfetch + merge を一発でSTEP 16
git fetchリモートの情報だけダウンロード用語
git fetch --pruneリモートに無いブランチ参照を削除—

一時退避 (Stash)

コマンド意味関連
git stash未コミットの変更を一時的に退避用語
git stash push -m "メモ"メッセージ付きで退避—
git stash list退避一覧—
git stash pop最新の退避を復元 (リストから削除)—
git stash apply復元するがリストには残す—
git stash drop最新の退避を破棄—
git stash clear退避をすべて破棄—

ファイル操作

コマンド意味関連
git rm <ファイル>ファイルを削除し、削除をステージング—
git rm --cached <ファイル>追跡対象から外す (ファイル自体は残す)STEP 18
git mv <旧> <新>ファイル名を変更 (履歴を保ちつつ)—

その他便利

コマンド意味関連
git help <コマンド>コマンドのヘルプを開く—
git <コマンド> --help同上 (短縮形)—
git reflogHEAD の移動履歴 (失敗からの復活に便利)—
git cherry-pick <コミットID>特定コミットだけを現ブランチに取り込む—
git clean -n未追跡ファイルを 確認だけ (削除せず)—
git clean -fd未追跡ファイル/フォルダを 削除 (危険)—
--hard や -D、clean -fd など 「強制」「破棄」 系のオプションは取り返しがつかない場合があります。実行前に git status で本当に消していい状態か確認しましょう。
