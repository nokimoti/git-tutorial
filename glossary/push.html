プッシュ (Push)

ローカル リポジトリ の変更を、リモート リポジトリに アップロード する操作。

使い方

# 通常のプッシュ
git push

# 初回のプッシュ (上流ブランチを覚えさせる)
git push -u origin main

イメージ

あなたのPC      ── push ──→      GitHub

よくある間違い

コミットしないとプッシュできません。「変更したのに反映されない」と思ったら、 git status でコミット済みか確認しましょう。

関連用語

  • プル — 逆方向の操作
  • origin — プッシュ先のリモート名
