リポジトリ (Repository)

Git で 変更履歴を保管する箱 のこと。あなたのファイルと、その過去の変更すべてが入っています。

もう少し詳しく

Git で管理しているフォルダには、必ず .git という隠しフォルダがあります。 この .git こそが「リポジトリの本体」で、ここにすべての コミット、ブランチ、設定が保管されています。

普段「リポジトリ」と言うときは、この .git を含む プロジェクトフォルダ全体 を指していることが多いです。

2種類のリポジトリ

  • ローカルリポジトリ = あなたのパソコン上にあるリポジトリ
  • リモートリポジトリ = GitHub などサーバ上のリポジトリ
