用語集

リバート (Revert)

git revert のこと。過去のコミットを「打ち消す」新しいコミットを作る 操作。元のコミットは履歴に残ったまま、その変更だけを無効化します。

イメージ

変更前: A ── B ── C ── D
                       ↑ D を打ち消したい

git revert D

変更後: A ── B ── C ── D ── D'
                            ↑ D の変更を取り消す内容のコミット

リセットとの違い

リバートリセット
履歴残る (打ち消しコミット追加)消える
共有済みコミット安全に使える危険 (使うべきでない)
用途公開後の取り消し未公開のローカル整理

使い方

git revert <コミットID>

実行するとエディタが立ち上がり、打ち消しコミットのメッセージを入力できます。デフォルトのままでも問題ありません。

マージコミットを revert する

git revert -m 1 <マージコミットID>

マージコミットには2つの親があるため、-m 1 で「1番目の親 (= 取り込み先) の方向に戻す」と明示が必要です。
