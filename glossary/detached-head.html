ディタッチド HEAD (Detached HEAD)

HEAD が ブランチではなく、特定のコミットを直接指している状態。「分離した」HEAD なのでこう呼ばれます。

いつ起きる?

過去の特定コミットを git checkout <ID> や git switch --detach <ID> で覗いたとき。 

git switch --detach abc1234

実行すると、git status にこんな警告が出ます。 

HEAD detached at abc1234

何が問題?

この状態でコミットを作っても、どのブランチにも所属しないコミット になります。 他のブランチに切り替えると、新しく作ったコミットへの目印が消えて事実上アクセス不能に。

ディタッチド HEAD で作業した変更を残したい場合は、必ず 新しいブランチを作って から離れること。

抜け出すには

普通の状態に戻るには、ブランチに切り替えます。

git switch main          # 既存ブランチに戻る
git switch -c new-branch # その地点を新ブランチにする (変更を保存)

困ったら reflog

ディタッチド HEAD で作ったコミットを「うっかり消した」ように見えても、git reflog で HEAD の移動履歴を辿れば復活できる場合があります。
