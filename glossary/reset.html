用語集

リセット (Reset)

git reset のこと。HEAD を別のコミットに「巻き戻す」 操作。3つのモード (soft / mixed / hard) で「どこまで巻き戻すか」を制御できます。

3つのモード

モードHEADステージングファイル用途
--soft移動そのままそのままコミットだけ取り消し、変更は再コミットしたい
(--mixed) ※デフォルト移動クリアそのままコミットとステージングを取り消し、編集は残す
--hard移動クリアクリアすべて巻き戻す (危険)

使い方の例

# 直前のコミットだけ取り消し (変更は手元に残す)
git reset --soft HEAD~1

# 直前のコミットとステージングを取り消し (編集は残る)
git reset HEAD~1

# 直前のコミットを変更ごと完全に破棄
git reset --hard HEAD~1

リバートとの使い分け

  • 未公開 (push 前) のコミット を整理 → git reset
  • 公開済み (push 済み) のコミット を取り消し → リバート
--hard は 未コミットの変更まで消えます。実行前に必ず git status で確認しましょう。 消したコミット自体は git reflog + git reset --hard <ID> でしばらくは復活できます。
