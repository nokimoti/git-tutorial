用語集

アップストリーム (Upstream)

ローカルブランチが「どのリモートブランチと連動しているか」を示す紐付け。これが設定されていれば git push や git pull を引数なしで実行できます。

初回プッシュで設定される

git push -u origin main

この -u がアップストリームを設定するオプションです。意味は 「ローカルの main ブランチは、リモート origin の main ブランチに push/pull するものとして覚えておいて」。

設定後は引数不要

git push   # → 自動で origin/main に送る
git pull   # → 自動で origin/main から取る

確認する

git branch -vv

ブランチごとに「どのリモートブランチに紐付いているか」が表示されます。 

* main f1e2d3c [origin/main] 最初のコミット

[origin/main] の部分がアップストリームの設定です。

後から設定/変更

git branch --set-upstream-to=origin/main main
