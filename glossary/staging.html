用語集

ステージング (Staging)

「次の コミット に含める変更」を一時的に置く場所、 または 変更をそこへ置く操作 のこと。

別名: インデックス

ステージングエリアは「インデックス (Index)」とも呼ばれます。同じものを指す別の言葉です。

なぜステージングがあるの？

ステージングがあるおかげで、たくさんファイルを編集していても 「今回はこの変更だけコミットしたい」 という選択ができます。 たとえば10ファイル変更したけど、3ファイルだけ意味のある変更で、残りはたまたま触っただけ、という場合に便利です。

ステージングへの追加と取り消し

# ステージングに追加
git add ファイル名

# まとめて全部追加
git add .

# ステージングから取り消し (編集内容は残る)
git restore --staged ファイル名

図で理解する

編集 → [ステージング] → コミット
       ↑ git add     ↑ git commit
