用語集

スタッシュ (Stash)

git stash のこと。未コミットの変更を一時的に「棚 (stash)」に退避 して、ワーキングディレクトリを最後のコミット時点に戻す操作。あとで取り出せます。

使う場面

  • 編集中だけど、急いで別のブランチに切り替えたい
  • git pull したいのに「未コミットの変更があります」と怒られる
  • 「まだコミットしたくないけど、現状を一旦リセットして実験したい」

基本の使い方

# 現在の変更を退避
git stash

# 退避した一覧を見る
git stash list

# 最新の退避を取り出す (リストから消える)
git stash pop

# 取り出すがリストには残す
git stash apply

メッセージ付きで退避

git stash push -m "ログイン画面の途中"

後から「あれ、これは何だったっけ?」となるのを防げます。

退避の捨て方

git stash drop          # 最新の退避を破棄
git stash clear         # すべての退避を破棄
