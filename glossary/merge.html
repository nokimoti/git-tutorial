用語集

マージ (Merge)

ある ブランチ での変更を、別のブランチに取り込む操作。 枝で実験した結果を、本流に合流させるイメージです。

使い方の例

feature ブランチの変更を main に取り込みたい場合:

  1. git switch main で取り込み先に移動
  2. git merge feature で合流

2種類の動き

  • Fast-forward — 取り込み先に新しいコミットがないとき。ラベルを動かすだけ
  • マージコミット — 両方に変更があるとき。新しいコミットを作って合流

うまくいかないとき

同じファイルの同じ箇所が両方で変更されていると、Git は判断できず コンフリクト が発生します。 落ち着いて手作業で解決しましょう。
