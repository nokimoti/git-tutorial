用語集

コミットID (ハッシュ)

各 コミット を一意に区別する 40文字の英数字 (SHA-1 ハッシュ)。コミットの「指紋」のようなもの。

例

f1e2d3c4b5a698765432abcdef1234567890abcd

短縮形

普段は最初の 7文字 だけで指定すれば十分です。Git が自動で「これだ」と判別してくれます。 

git show f1e2d3c
git revert f1e2d3c

なぜハッシュ?

  • コミットの内容 (変更・親コミット・作者・日時など) すべてから自動計算される
  • 1文字でも違えば全く違うIDになる → 同じIDのコミットは存在しない
  • 履歴を改ざんすると IDが変わるので、検出可能

関連用語

  • コミット
  • HEAD — 「現在のコミットID」を指す目印
