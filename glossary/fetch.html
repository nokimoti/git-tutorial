フェッチ (Fetch)

リモート リポジトリの最新情報を ダウンロードだけする 操作。 ローカルの作業ブランチには反映しません。

pull との違い

  • fetch = ダウンロードのみ (作業中のファイルは変わらない)
  • pull = ダウンロード + マージ (作業中のファイルが更新される)

つまり git pull = git fetch + git merge です。

fetch を使うメリット

「リモートに何か新しい変更があるか確認だけしたい」というとき、fetch なら手元の作業を邪魔しません。 確認してから自分のタイミングでマージできるので、慎重派にはこちらが向いています。

使い方

git fetch
git log origin/main   # リモートの最新コミットを確認できる
git merge origin/main # 問題なさそうなら手動でマージ

初心者は pull で OK

最初のうちは git pull だけ覚えていれば十分です。 fetch は「pull は便利だけど、自動マージが怖いと感じてきた」段階で使い始めれば良いものです。
