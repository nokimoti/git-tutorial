オブジェクト (Git Object)

Git が内部で扱う 「データの最小単位」。4種類あり、すべて ハッシュ で識別され、.git/objects/ 内に保管されています。

4種類のオブジェクト

種類役割詳細
blobファイルの中身A2
treeフォルダ構造 (ファイル名 + blob)A3
commitスナップショットへの参照 + メタ情報A4
tag (注釈付き)コミットへの注釈付き目印タグ

オブジェクトの大事な性質

  • 不変 (immutable) — 一度作られたら変更されない。書き換えではなく「新しいオブジェクトを作る」だけ
  • ハッシュで識別 — 内容のハッシュがそのまま ID
  • 同じ内容は1つだけ — 重複は自動的に排除される
  • 互いに参照しあう — commit が tree を、tree が blob を、commit が parent commit を…

どこに保管される?

.git/objects/<ハッシュの先頭2文字>/<残り38文字>

例: ハッシュ ce013625030ba8... の場合:

.git/objects/ce/013625030ba8...

関連用語

  • ハッシュ — オブジェクトのIDの正体
  • コミット — commit オブジェクトの説明
  • タグ — tag オブジェクトの説明
