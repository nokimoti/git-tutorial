GitHub Pages

GitHub が提供する 無料の静的サイトホスティング サービス。リポジトリにある HTML/CSS/JS を、URL付きで Web に公開できます。

典型的な URL

https://<ユーザー名>.github.io/<リポジトリ名>/

たとえば nokimoti さんの git-tutorial リポジトリなら: 

https://nokimoti.github.io/git-tutorial/

有効化のしかた

  1. GitHub のリポジトリページ → Settings
  2. 左メニューの Pages
  3. 「Source」で「Deploy from a branch」を選ぶ
  4. Branch: main、フォルダ: / (root)
  5. 「Save」をクリック
  6. 1〜2分待って同じページをリロードすると、上部に公開URLが表示

制約

  • 静的ファイルのみ (PHP・Ruby などのサーバ処理は不可)
  • リポジトリは Public である必要あり (無料プランの場合)
  • 1リポジトリにつき配信できるのは1ブランチ
  • サイズ上限: 1GB、月間転送量: 100GB (ソフトリミット)

更新のしかた

設定したブランチに git push すれば、自動で再デプロイされます (1〜2分)。CSS や HTML を編集して push するだけ。
