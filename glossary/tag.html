用語集

タグ (Tag)

特定の コミット につける 動かない目印。 リリース版に v1.0.0 のような名前をつけるのに使います。

ブランチとの違い

  • ブランチ — 動く印 (新コミットが増えると先頭が動く)
  • タグ — 動かない印 (一度つけたら永遠にそのコミットを指す)

2種類のタグ

  1. 軽量タグ (lightweight) — ただの名札
  2. 注釈付きタグ (annotated) — 作者・日付・メッセージを持つ正式なタグ

リリース用には注釈付きタグの利用が推奨されています。

主なコマンド

git tag -a v1.0.0 -m "最初の正式版"   # 注釈付きタグを作成
git tag                                # 一覧
git show v1.0.0                        # 詳細を見る
git tag -d v1.0.0                      # 削除
git push origin v1.0.0                 # リモートに送る (push は自動ではない)
git push --tags                        # 全タグをまとめて送る

命名の慣例

セマンティックバージョニング がよく使われます: v[メジャー].[マイナー].[パッチ]
