用語集

.git ディレクトリ

git init や クローン したフォルダの中に作られる Git の管理データ本体 (隠しフォルダ)。すべてのコミット・ブランチ・タグ・設定がここに収まっています。

中に入っているもの (一部)

  • HEAD — 現在のブランチを指すファイル
  • config — リポジトリ固有の設定
  • objects/ — 全コミット・ファイル内容のスナップショット
  • refs/ — ブランチやタグの参照
  • logs/ — HEAD・ブランチの移動履歴
  • index — ステージング エリアの実体

絶対に手で触らない

.git フォルダを手動で削除・編集すると、これまでの履歴が完全に失われたり壊れたりします。Git コマンド経由でしか触らないこと。

「ただのフォルダ」を「Gitリポジトリ」に変える正体

git init がやっているのは、実質的に このフォルダを作る だけ。逆に .git を消せば、フォルダは Git の管理外に戻ります。
