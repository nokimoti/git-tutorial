用語集

origin

リモート リポジトリの URL に 付ける呼び名 (エイリアス)。 最初のリモートには origin という名前を付けるのが Git の慣例です。

仕組み

長い URL を毎回打たなくてすむように、リモートには短い名前を付けて呼びます。 

# origin = "https://github.com/.../repo.git" の別名として登録
git remote add origin https://github.com/.../repo.git

# 以降、URL の代わりに origin と書ける
git push origin main
git pull origin main

origin はただの名前

origin という名前は、特別な意味があるわけではありません。慣例で使われているだけです。 希望すれば github でも backup でも好きな名前を付けられます。ただし、混乱の元なので 特別な理由がない限り origin のままでOK。

クローンしたリポジトリでは自動設定

git clone したリポジトリでは、クローン元の URL が自動的に origin として登録されます。
