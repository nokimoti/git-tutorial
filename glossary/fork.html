用語集

フォーク (Fork)

GitHub の機能。他人のリポジトリを「自分のアカウント上にコピー」 する操作。コピーされたリポジトリは自分の所有物として自由に編集でき、必要なら元の作者に プルリクエスト で変更を提案できます。

クローンとの違い

フォーククローン
コピー先GitHub 上 (自分のアカウント)自分のパソコン
書き込み権限あり (自分のもの)あり (ローカル)
用途他人のリポジトリに貢献したい編集環境を手元に作りたい

典型的な流れ

  1. GitHub で対象リポジトリを開いて、右上の「Fork」ボタン
  2. 自分のアカウントにコピーが作られる
  3. そのコピーを git clone で手元に持ってくる
  4. 新しいブランチを切って改修
  5. 自分のフォークに push
  6. 元のリポジトリに プルリクエスト を出す

使う場面

  • OSS (オープンソース) に貢献したい
  • 他人のテンプレートを土台にして自分用に改造したい
  • 書き込み権限のないリポジトリで実験したい
