用語集

.gitignore

Git に 「このファイル/フォルダは管理しないで」と伝える設定ファイル。 リポジトリの直下に置きます。

典型的に無視するもの

  • パスワード・秘密鍵 (.env など) — 公開すると危険
  • ビルド成果物 (node_modules/, dist/) — 重い & 自動生成できる
  • OS の隠しファイル (.DS_Store, Thumbs.db)
  • エディタ設定 (.idea/, .vscode/ の一部)

書き方

# コメントは # で始める

# 特定のファイル
secret.txt

# 拡張子で指定
*.log

# フォルダ全体
node_modules/

# 例外的に管理する (! で除外)
!important.log

注意

すでにコミットしてしまったファイル は、後から .gitignore に追加しても無視されません。 その場合は git rm --cached <ファイル名> でリポジトリから削除してから、コミットし直す必要があります。

テンプレート集

  • github.com/github/gitignore — 公式テンプレート
  • gitignore.io — 言語/ツール名で自動生成
