用語集

コンフリクト (Conflict)

マージ や プル のときに、 同じ箇所が異なる方法で変更されていて、Git が自動で判断できない状態。 日本語では「衝突」と訳されます。

コンフリクトは異常ではなく正常な動作

コンフリクトは「失敗」ではなく、Git が「ここはあなたが判断してください」と人間に委ねる仕組みです。 落ち着いて1箇所ずつ片付けていけば必ず解決できます。

コンフリクトの目印

コンフリクトしたファイルには、こんな記号が挿入されます。

<<<<<<< HEAD
こちら側の内容 (現在のブランチ)
=======
あちら側の内容 (取り込もうとしているブランチ)
>>>>>>> feature

解決の手順

  1. テキストエディタでコンフリクトしているファイルを開く
  2. 記号を見ながら、最終的な内容を編集する (どちらかを選ぶ・両方を組み合わせる など)
  3. <<< === >>> の記号を すべて消す
  4. git add で解決済みとマーク
  5. git commit で完了

マージをやめたいとき

git merge --abort

マージを中止して、コンフリクト前の状態に戻れます。
