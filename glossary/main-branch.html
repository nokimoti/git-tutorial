用語集

main ブランチ

リポジトリの 本流となる ブランチ。 git init で作ったリポジトリには、最初からこの main ブランチがあります。

位置づけ

多くのプロジェクトで、main は次のような役割を持ちます。

  • 常に動作する最新の状態を保つ
  • 他のブランチ (機能ブランチなど) はここから分岐する
  • リリースされる安定版は最終的にここにマージされる

master との違い

昔は master という名前が使われていました。今でも古いリポジトリでは見かけますが、 新しく作られるリポジトリでは main が標準になっています (GitHub のデフォルトも 2020 年から main)。 機能的にはまったく同じものです。

main ブランチの確認

# いまのブランチを表示
git branch

# main に切り替え
git switch main

関連用語

  • ブランチ — ブランチ全般の説明
  • HEAD — main にいるとき HEAD は main を指す
