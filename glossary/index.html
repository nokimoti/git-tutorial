用語集

Git の学習でよく出てくる専門用語の一覧です。各用語をクリックすると詳しい説明ページに飛びます。 文中で こんなふうに 表示される語はすべてここにリンクされています。

基本

リポジトリ
変更履歴の入れ物
コミット
変更のセーブポイント
コミットID
コミットの「指紋」 (ハッシュ)
ワーキングディレクトリ
普段ファイルを編集する場所
ステージング
コミット前の一時置き場
HEAD
いま見ているコミットを示す目印
ディタッチド HEAD
ブランチを離れた HEAD 状態
.git ディレクトリ
履歴データの本体

ファイルの状態

追跡 / 未追跡
Git 管理対象かどうか
.gitignore
無視するファイルを指定

ブランチ・タグ関連

ブランチ
履歴の枝分かれ
main ブランチ
本流となるブランチ
マージ
ブランチを統合する操作
ファストフォワード
マージの一種 (早送り)
コンフリクト
マージ時の衝突
タグ
特定コミットの動かない目印
チェックアウト
古い切替コマンド (旧 checkout)

変更の取り消し・整理

アメンド
直前のコミットを書き換える
リバート
打ち消しコミットを作る
リセット
HEAD を巻き戻す (3モード)
リベース
履歴を別ブランチ上に積み直す
スタッシュ
未コミット変更を一時退避

リモート関連

リモート
サーバ上のリポジトリ
origin
リモートの慣習的な呼び名
アップストリーム
ローカル↔リモートの紐付け
プッシュ
ローカル → リモートへ送る
プル
リモート → ローカルへ取り込む
フェッチ
リモートの情報だけ取得
クローン
リモートを丸ごと複製

GitHub 関連

プルリクエスト
変更取り込みの依頼 (PR)
フォーク
他人リポジトリのコピーを作る
GitHub Pages
無料の静的サイトホスティング
