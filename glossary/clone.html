クローン (Clone)

リモート にある リポジトリ を、履歴ごと丸ごと自分のパソコンに複製する操作。

使い方

git clone https://github.com/<ユーザー名>/<リポジトリ名>.git

このコマンドを実行すると、現在の場所の下に新しいフォルダができ、リポジトリの全内容が入ります。

クローンの便利なところ

  • 過去のすべてのコミット履歴も一緒にコピーされる
  • origin が自動で設定済み
  • クローン直後から push / pull が使える
