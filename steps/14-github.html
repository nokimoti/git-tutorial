STEP 14

GitHub のアカウントを作る

このステップのゴール

  • GitHub のアカウントを取得する
  • GitHub 上に空のリポジトリを作っておく

GitHub とは何か (改めて)

GitHub は、Git のリポジトリをインターネット上に置けるサービスです。 これによって以下のことが可能になります。

  • 自分のコードをバックアップできる (パソコンが壊れても安心)
  • 他のパソコンと同期できる (会社と自宅、両方で同じコードを編集)
  • 他の人と一緒に作業できる (チーム開発)
  • 世界中の人にコードを公開できる

アカウントを作る

  1. github.com/signup にアクセス
  2. メールアドレスを入力 → 「Continue」
  3. パスワードを設定 → 「Continue」
  4. ユーザー名を決める (英数字とハイフンのみ。後で変更も可能)
  5. あとは画面の指示に従う (アンケート画面はスキップしてOK)
  6. 登録したメールに届く確認コードを入力して、登録完了
無料プランで個人開発には十分な機能が使えます。クレジットカードは不要です。

非公開メールアドレスを使う設定 (推奨)

STEP 03 で説明したとおり、コミットに記録されるメールアドレスは公開されてしまうリスクがあります。 GitHub には、自分のメールアドレスを隠せる仕組みがあります。

  1. GitHub にログイン
  2. 右上のアバター → 「Settings」
  3. 左メニューの「Emails」
  4. 「Keep my email addresses private」にチェック
  5. すぐ上に表示される 12345678+ユーザー名@users.noreply.github.com 形式のアドレスをコピー
  6. このアドレスを Git の user.email に設定: 
    git config --global user.email "12345678+ユーザー名@users.noreply.github.com"

GitHub 上に空のリポジトリを作る

自分のパソコンにあるリポジトリを GitHub にアップロードする準備として、 GitHub 側に「受け皿」となる空のリポジトリを作りましょう。

  1. GitHub のトップページ右上の「+」ボタン → 「New repository」
  2. 「Repository name」に名前を入力 (例: my-first-repo)
  3. 公開範囲を選ぶ
    • Public = 誰でも見られる
    • Private = 自分と招待した人だけ見られる
  4. その他のチェックボックスは すべて空のまま にする
    「Add a README file」「Add .gitignore」「Choose a license」のチェックは 絶対につけない でください。 これらにチェックすると、自分のローカルリポジトリと衝突して連携が面倒になります。
  5. 「Create repository」をクリック

作成後の画面に、リポジトリの URL が表示されます。次のステップで使うので、画面はこのまま開いておいてください。

https://github.com/<ユーザー名>/my-first-repo.git

(任意) GitHub Desktop でログイン

GUI 派の方は、GitHub Desktop に GitHub アカウントでログインしておくと便利です。

  1. GitHub Desktop を開く
  2. 「File」 → 「Options」 → 「Accounts」
  3. GitHub.com の「Sign in」をクリック
  4. ブラウザが開くので、GitHub にログイン
  5. 「Authorize desktop」ボタンで承認

このステップのまとめ

  • GitHub アカウントは無料で作れる
  • 非公開メールアドレスを使うと、メールアドレスが公開されない
  • GitHub 上に 空の リポジトリを作っておくのが大事 (チェックボックスはつけない)
