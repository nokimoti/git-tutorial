STEP 07

変更履歴を見る (log)

このステップのゴール

  • 過去のコミットを一覧表示できるようになる
  • 各コミットを区別する「コミットID」の存在を知る

練習: 2回目のコミットを残す

STEP 06 で編集した hello.txt を、もう一度コミットしましょう (流れの復習です)。 

git add hello.txt
git commit -m "ステータス確認の練習行を追加"

これで、リポジトリに2つのコミットが残った状態になりました。

git log で履歴を見る

git log

こんなふうに表示されます。

commit f1e2d3c4b5a6... (HEAD -> main)
Author: Taro Yamada <taro@example.com>
Date:   Fri May 8 14:30:25 2026 +0900

    ステータス確認の練習行を追加

commit 9876abc...
Author: Taro Yamada <taro@example.com>
Date:   Fri May 8 14:00:10 2026 +0900

    最初のコミット

新しいコミットが上、古いコミットが下に並びます。

画面の下に : という記号が出ていたら、キーボードの「q」を押すと元のプロンプトに戻れます。

もっとコンパクトに見る

git log --oneline

1コミット1行に短縮されて、ぱっと見がわかりやすくなります。

f1e2d3c (HEAD -> main) ステータス確認の練習行を追加
9876abc 最初のコミット

グラフ付きで見る (おすすめ)

git log --oneline --graph --all

将来 ブランチ を使うようになると、この表示が威力を発揮します。

GitHub Desktop で履歴を見る

  1. 上部のタブで「History」をクリック
  2. 左側にコミット一覧が、最新のものが上に表示される
  3. コミットをクリックすると、右側にそのコミットでの変更内容 (差分) が表示される

git log よりはるかに直感的です。コミット日時、メッセージ、変更ファイル、差分まですべて1画面で確認できます。

コミットIDって何？

f1e2d3c4b5a6... のような長い英数字は コミットID (ハッシュ) と呼ばれます。 これはコミットを一意に区別する「指紋」のようなものです。

  • 同じコミットが2つ存在することはない (中身が違えばIDも違う)
  • 普段は最初の7文字 (f1e2d3c) だけで指定すれば十分
  • 「あのコミットに戻したい」というときに、このIDを使う

HEAD という言葉

git log の出力には (HEAD -> main) という表示が出ます。 HEAD は「いま自分がどのコミットを見ているか」を指す矢印です。 ブランチ操作 (STEP 09 以降) で何度も出てくる言葉なので、頭の片隅に置いておきましょう。

このステップのまとめ

  • git log で履歴を一覧できる
  • git log --oneline でコンパクト表示
  • コミットには「コミットID」という指紋がある
  • HEAD = いま見ているコミットを指す矢印
