STEP 02

Git をインストールする

このステップのゴール

  • 自分のパソコンに Git を入れる
  • (GUI を使う場合) GitHub Desktop もインストールする
  • インストールが成功したかを確認する

Git本体のインストール

Windows の場合

  1. git-scm.com の Windows ダウンロードページ にアクセスする
  2. 「64-bit Git for Windows Setup」をダウンロード
  3. ダウンロードしたインストーラを起動する
  4. 基本は 「Next」を押し続ければ OK です。デフォルト設定で進めましょう
  5. インストールが終わると、スタートメニューに Git Bash が追加されます
Git Bash は Windows で bash コマンドを使うための小さなターミナルです。 このサイトで「bash でこう入力」と書いてあるところは、すべて Git Bash で実行してください。

macOS の場合

ターミナル (アプリ「ターミナル.app」) を開いて、次のコマンドを実行します。

git --version

まだ Git が入っていない場合は、Xcode コマンドラインツールのインストールを促されるので、 「インストール」を押すだけで完了します。

Homebrew が入っている方なら、より新しい Git を入れることもできます。 

brew install git

Linux の場合

ディストリビューションに応じて、次のいずれかを実行します。

Ubuntu / Debian:

sudo apt update
sudo apt install git

Fedora / RHEL:

sudo dnf install git

Arch:

sudo pacman -S git

インストールできたか確認する

ターミナル (Windows なら Git Bash) を開いて、次のコマンドを実行してみましょう。

git --version

「git version 2.xx.x」のように数字が表示されたら成功です。 お疲れさまでした。これで Git 本体は使える状態になりました。

もし「git: command not found」のように表示された場合は、 ターミナルを一度閉じてから再起動してみてください。それでも改善しない場合は、 インストールが失敗している可能性があるので、もう一度ダウンロードからやり直しましょう。

(任意) GitHub Desktop をインストールする

GUI で Git を操作したい人は、GitHub Desktop も一緒に入れておくのがおすすめです。 初心者にも優しい、無料のツールです。

  1. desktop.github.com にアクセスする
  2. 「Download for Windows」または「Download for macOS」をクリック
  3. ダウンロードしたインストーラを起動して、案内のとおりに進める
VS Code を普段使っている方は、VS Code に最初から Git 機能が入っています。 別途インストールは不要で、左サイドバーの「ソース管理」アイコンからすぐ使えます。

このステップのまとめ

  • git --version でバージョンが表示されればインストール成功
  • Windows では「Git Bash」を使ってコマンドを実行する
  • GUI 派は「GitHub Desktop」または「VS Code の Git」を使う
