STEP 04

はじめてのリポジトリを作る

このステップのゴール

  • 練習用のフォルダを リポジトリ にする
  • .git という隠しフォルダの存在を理解する

練習用のフォルダを準備する

まずは練習のため、新しいフォルダを作りましょう。場所はどこでも構いませんが、 ここでは my-first-repo という名前で作ります。

例:

  • Windows: C:\Users\あなたの名前\Documents\my-first-repo
  • macOS / Linux: ~/Documents/my-first-repo

エクスプローラー (Finder) で普通にフォルダを新規作成すれば OK です。

リポジトリにする (= Git の管理を始める)

bash で初期化する

ターミナルで、作ったフォルダに移動します。

cd ~/Documents/my-first-repo

そして、次のコマンドを実行するだけ。

git init

次のような表示が出ます。 

Initialized empty Git repository in /Users/.../my-first-repo/.git/

これで完了。このフォルダは Git のリポジトリになりました。

GitHub Desktop で初期化する

  1. GitHub Desktop を起動する
  2. メニューから File → New repository... を選ぶ
  3. 表示されたダイアログで以下を入力:
    • Name: my-first-repo
    • Local path: 保存場所を指定 (例: Documents フォルダ)
    • そのほかはデフォルトのままで OK
  4. 「Create repository」を押す

指定した場所に my-first-repo フォルダが自動で作られ、すでに Git の管理下になっています。

.git フォルダって何？

リポジトリにすると、フォルダの中に .git という名前の隠しフォルダが作られます。 ここに、Git が管理するすべての履歴情報が入っています。

隠しフォルダを表示する方法:

  • Windows: エクスプローラーの「表示」→「隠しファイル」にチェック
  • macOS: Finder で ⌘ + Shift + . を押す
  • bash: ls -a と入力する
.git フォルダは 絶対に手動で消したり編集したりしないでください。 消してしまうと、これまでの履歴がすべて失われます。気にせず存在を忘れて大丈夫です。

もう少し詳しい仕組み

git init したフォルダは、3つの領域から成り立っていると考えてください。

  • ワーキングディレクトリ — あなたが普段ファイルを編集する場所
  • ステージングエリア — 「次のコミットに含める変更」を一時的に置く場所
  • リポジトリ (.git 内) — 過去のすべてのコミットを保管する場所

この3つを行ったり来たりしながら、変更を保存していくのが Git の使い方です。 次のステップで、実際の流れを体験します。

このステップのまとめ

  • フォルダの中で git init すれば リポジトリ になる
  • .git フォルダが作られるが、絶対に触らない
  • 3つの領域 (ワーキングディレクトリ・ステージング・リポジトリ) をイメージで理解する
