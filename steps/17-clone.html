STEP 17

リポジトリをクローンする

このステップのゴール

  • GitHub にあるリポジトリを、まるごと自分のパソコンに持ってこられるようになる
  • クローン と git init の違いを理解する

クローンってどんな場面で使う？

クローン は、リモートにあるリポジトリを丸ごと複製してローカルに持ってくる操作です。 こんな場面で使います。

  • 会社のリポジトリを自宅のパソコンでも触りたい
  • 新しいパソコンを買ったので、これまでのリポジトリを持ってくる
  • GitHub で誰かが公開しているライブラリを使いたい
  • チームの新メンバーになって、開発中のプロジェクトに参加する
クローンには、過去のすべてのコミット履歴も丸ごと含まれます。単なるダウンロードではなく、「リポジトリ全体のコピー」です。

クローンの URL を取得する

まず GitHub のリポジトリページを開いて、緑色の「Code」ボタンをクリックします。 表示される URL がクローン用の URL です。 

https://github.com/<ユーザー名>/my-first-repo.git
URL 入力欄の右側にあるコピーアイコンをクリックすると、ワンタッチでコピーできます。

クローンする

① クローン先の場所に移動

クローンしたいフォルダ (例: ドキュメント) に移動します。

cd ~/Documents

② クローンを実行

git clone https://github.com/<ユーザー名>/my-first-repo.git

実行すると、現在の場所の下に my-first-repo という名前のフォルダができ、 その中にリポジトリの全ファイルと履歴が入っています。

③ クローンしたフォルダに入る

cd my-first-repo
git log --oneline

すべてのコミット履歴が見られるはずです。

違う名前のフォルダにしたいときは、URL の後ろにフォルダ名を指定できます: 
git clone <URL> my-new-name

GitHub Desktop でクローン

  1. 「File」メニュー → 「Clone repository...」
  2. 「GitHub.com」タブを選ぶと、自分のリポジトリ一覧が出る
  3. クローンしたいリポジトリを選ぶ
  4. 下の「Local path」で保存先を指定
  5. 「Clone」をクリック

他人のリポジトリをクローンしたいときは、「URL」タブを選んで URL を入力します。

クローンしたあとは？

クローンしたリポジトリは、もう完全に「使える状態」です。 git remote -v を見ると、自動で origin が設定されているのがわかります。

つまり、クローンしてすぐに:

  • 編集 → コミットができる
  • git push でリモートに送れる
  • git pull でリモートの変更を取り込める

すべて準備済み、というわけです。

git init との違い

操作 使う場面
git init 手元のフォルダを新しく Git 管理にする
git clone すでにある リモートリポジトリをコピーしてくる

このステップのまとめ

  • git clone <URL> で、リモートのリポジトリを丸ごと取得
  • クローンしたフォルダは origin 設定済みで、すぐ push / pull できる
  • 新規作成は init、既存を持ってくるのは clone
