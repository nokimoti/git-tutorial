STEP 03

初期設定 (名前とメールアドレス)

このステップのゴール

  • Git に「あなたが誰なのか」を教える
  • コミット に名前とメールアドレスが記録されるようにする

なぜ初期設定が必要？

Git では、すべての コミット に「誰が変更したか」という情報が記録されます。 そのため Git に対して、最初に あなたの名前とメールアドレス を教えておく必要があります。

この設定は 1度やれば、ずっと有効 です。パソコンを買い替えるか、Git を入れ直すまでは再設定不要です。

bash で設定する

ターミナル (Windows なら Git Bash) を開いて、次のコマンドを順に実行します。

git config --global user.name "あなたの名前"
git config --global user.email "your@example.com"

例えば「山田太郎」さんなら、こう入力します。 

git config --global user.name "Taro Yamada"
git config --global user.email "taro@example.com"

--global をつけると、このパソコン全体に設定が反映されます。

設定できたか確認する

次のコマンドで現在の設定を確認できます。

git config --global user.name
git config --global user.email

入力した名前とメールアドレスが表示されたら成功です。

GitHub Desktop で設定する

  1. GitHub Desktop を起動する
  2. メニューから File → Options (Windows) または GitHub Desktop → Settings (Mac) を開く
  3. 左の「Git」タブを選択
  4. Name 欄にあなたの名前、Email 欄にメールアドレスを入力
  5. 「Save」を押して完了
GitHub Desktop で設定すると、内部的には git config --global と同じ設定が書き込まれます。 bash でも同じ設定として扱われるので安心してください。

メールアドレスの注意点

ここで設定したメールアドレスは、将来 GitHub にコミットを公開したときに 誰でも見える状態 になります。 公開したくない場合は、GitHub が提供する非公開メールアドレス (xxxxx@users.noreply.github.com 形式) を使うとよいでしょう。 これは STEP 14 で再度説明します。

(任意) よく使う設定

初心者のうちは不要ですが、慣れてきたら次の設定もおすすめです。

# デフォルトのブランチ名を main にする
git config --global init.defaultBranch main

# 改行コードの自動変換 (Windows の方向け)
git config --global core.autocrlf true

このステップのまとめ

  • git config --global user.name と user.email で自分を登録する
  • 1度だけやれば OK の設定
  • GUI を使う場合は GitHub Desktop の設定画面でも同じことができる
