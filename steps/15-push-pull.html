STEP 15

プッシュとプル

このステップのゴール

  • ローカルの変更を GitHub に プッシュ できるようになる
  • GitHub の変更を プル でローカルに取り込めるようになる

プッシュとプルの関係

リモート と連携した後の作業は、ほぼこの2つの操作だけです。

  • プッシュ (push) = ローカルの変更を、リモート (GitHub) にアップロード
  • プル (pull) = リモートの変更を、ローカルにダウンロード
あなたのPC                          GitHub
┌─────────────┐ ── push ──→         ┌─────────────┐
│ ローカル    │                     │ リモート    │
│             │ ←── pull ──         │             │
└─────────────┘                     └─────────────┘

はじめてのプッシュ

初回プッシュは -u をつける

git push -u origin main

意味を分解すると:

  • git push = プッシュする
  • origin = STEP 14 で設定したリモートの呼び名
  • main = プッシュするブランチ
  • -u = 「次回からは git push だけでこの場所に送れるよう覚えておいて」の意

コマンドを実行すると、初回はブラウザが自動で開いて GitHub への認証を求められます。 指示に従って認証を完了させてください。

成功するとこんな表示が出ます。

Enumerating objects: 6, done.
...
To https://github.com/.../my-first-repo.git
 * [new branch]      main -> main
branch 'main' set up to track 'origin/main'.

2回目以降のプッシュ

git push

これだけで OK。-u で覚えさせた設定が効いています。

GitHub Desktop でプッシュ

コミットを作ると、画面上部に「Push origin」ボタンが現れます。

  1. 「Push origin」ボタンをクリック
  2. 初回は GitHub への認証ダイアログが出るので、画面の指示に従う
  3. 完了すると、ボタンの数字 (送信待ちのコミット数) がリセットされる

これだけ。GUI ならコマンドを覚える必要がないのが楽です。

GitHub で確認してみる

ブラウザで GitHub のリポジトリページを開いて (リロードして) みましょう。 hello.txt がアップロードされ、コミット履歴も全部見られるはずです。

ここまで来たら、もうあなたのコードは安全です。 パソコンが故障しても、GitHub にコピーが残っています。

プルしてみる

練習として、GitHub 上で直接ファイルを編集 して、それをローカルにプルしてみましょう。

① GitHub 上で編集する

  1. GitHub のリポジトリページで hello.txt をクリック
  2. 右上の鉛筆アイコン (Edit this file) をクリック
  3. 1行追加: GitHub から直接編集した行。
  4. 右上の「Commit changes...」 → 「Commit changes」

② ローカルにプルする

git pull

こんな表示が出れば成功。

Updating f1e2d3c..abcd789
Fast-forward
 hello.txt | 1 +
 1 file changed, 1 insertion(+)

ローカルの hello.txt にも、追加した行が反映されているはずです。

  1. GitHub Desktop の上部に「Pull origin」ボタンが現れる
    (ボタンが見えないときは「Repository」メニュー → 「Pull」)
  2. クリックすればプル完了

fetch と pull の違い

Git にはもうひとつ フェッチ (fetch) という操作があります。

  • fetch = リモートの最新情報をダウンロードするだけ (作業中ブランチには反映しない)
  • pull = fetch + merge をまとめてやる

要するに git pull は「ダウンロードして自動でマージする」ショートカットです。 初心者のうちは git pull だけ使えば困りません。

このステップのまとめ

  • ローカル → リモートに送る = プッシュ (git push)
  • リモート → ローカルに取り込む = プル (git pull)
  • 初回プッシュは git push -u origin main
