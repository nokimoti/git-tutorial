このサイトについて

このサイトは、Git をまったく触ったことのない方を対象に、 ひとつずつ小さなステップで学べるように作られています。 各ステップは コマンドライン (bash) と GUI の両方の手順を併記しているので、 自分のスタイルに合わせて学習できます。

文中の専門用語は こんなふうに リンクになっています。 意味がわからなくなったら、リンクをクリックすると用語の説明ページにジャンプできます。

学習の流れ

STEP 01 — 02
準備編
Git とは何か、インストールから始めます。
STEP 03 — 08
基本操作編
リポジトリ作成、コミット、履歴確認まで。
STEP 09 — 12
ブランチ編
ブランチを作って分岐・統合する操作を学びます。
STEP 13 — 17
GitHub・応用編
リモートリポジトリと共同作業のための知識。

このサイトで前提とする環境

  • OS: Windows / macOS / Linux いずれでも対応
  • コマンドライン: bash (Windows では Git Bash)
  • GUI ツール: GitHub Desktop または VS Code の Git 機能 を例に解説します
コマンドラインに慣れていなくても大丈夫です。GUI だけ読み進めても操作を完結できるよう作っています。

はじめての方へ

まずは STEP 01: Git とは何か からゆっくり読み進めてみてください。 1ステップあたり 5〜10分程度で読み終わるボリュームになっています。
