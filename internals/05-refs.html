しくみ A5

参照 (ref) — ブランチもHEADもタグも、ただのテキストファイル

このステップのゴール

  • ブランチの正体が 「コミットIDを書いた1行のテキストファイル」 だと知る
  • HEAD は「ブランチを指すファイル」と理解する
  • なぜブランチ作成が一瞬で終わるのか、その理由が分かる

「参照 (ref)」の正体

ブランチ・HEAD・タグ (軽量タグ) は すべて参照 (ref) と呼ばれる仕組み で、 実体は .git/ 内に置かれた 1行のテキストファイル です。

「ref」 = reference (参照) の略。「あのコミットを指してるよ」というメモのこと。 重要なのは、ref は オブジェクトそのものではない ということ。 オブジェクトは中身 (commit や blob)、ref は「それを指す目印」。役割がきれいに分かれています。

① ブランチの正体

たとえば main ブランチの実体は、こんなファイル: 

.git/refs/heads/main

中身を見ると、たった1行のハッシュが書かれているだけ。 

$ cat .git/refs/heads/main
f1e2d3c4b5a698765432abcdef1234567890abcd

これが「main は今このコミットを指しています」という宣言の正体です。 experiment という新しいブランチを作るのも、同じ場所に .git/refs/heads/experiment という1行ファイルを置くだけ。

これがブランチ作成が一瞬で終わる理由。ファイルを1つ作るだけ なので、いくらブランチを切ってもストレージ的にはほぼ無料です。

新しいコミットでブランチが「動く」しくみ

git commit したとき、Git は次の処理をします:

  1. 新しいコミットオブジェクトを作る (親 = 今のブランチが指すコミット)
  2. ブランチのファイルを書き換えて、新コミットを指すようにする

たったこれだけ。「ブランチが進む」とは、.git/refs/heads/main ファイルの中身を新しいハッシュに上書きする操作だったのです。

② HEAD の正体

HEAD も、やはりファイル: 

.git/HEAD

中身は通常、こうなっています: 

$ cat .git/HEAD
ref: refs/heads/main

HEAD は「現在のブランチ」を1段階の間接参照で指している。直接コミットを指しているのではなく、「main ブランチを見てね」と指示するだけ。

「間接参照」って? 「これを見て」と書いてあるメモを開いて、そこに書かれた本物を見る、という二段構えの参照方法のこと。たとえるなら:
  • HEAD = 「main 棚を見て」と書いた紙
  • main = 「コミット f1e2d3c... を見て」と書いた紙
  • commit = 本物のデータ
この間接参照のおかげで、ブランチを切り替えるときは HEAD ファイル1つを書き換えるだけ で済むのです。

ブランチ切替 = HEAD ファイルの書き換え

git switch experiment を実行すると、Git がやっているのは: 

$ cat .git/HEAD
ref: refs/heads/experiment      ← この1行が書き換わるだけ!

あとはワーキングディレクトリを experiment が指すコミットの内容に合わせるだけ。

ディタッチド HEAD のとき

ディタッチド HEAD (= ブランチを介さず直接コミットを見ている状態) では、HEAD ファイルの中身が ref: ... ではなく 直接 コミットID になります。 

$ cat .git/HEAD
abc1234567890...   ← 直接ハッシュを指している

「ブランチを通さずコミットを直接見ている」状態がそのままファイルに表れている、というわけ。

③ タグ の正体

軽量タグ (= シンプルな目印タグ) もブランチと同じく、ただのファイル: 

.git/refs/tags/v1.0.0

中身もブランチと同じく、コミットハッシュが1行入っているだけ。違うのは「動かない」 (= 新しいコミットが来ても自動更新されない) という運用ルールだけです。

一方、注釈付きタグ (= 作者・メッセージ付きの正式なタグ) は別格で、「タグオブジェクト」という独立した オブジェクト を作ります (これが4種類目のオブジェクト)。 ファイルの中身はそのタグオブジェクトのハッシュ。

全体図 (ふたたび)

.git/HEAD
   "ref: refs/heads/main"          ← 文字列で main ブランチを指す
       │
       ▼
.git/refs/heads/main
   "f1e2d3c..."                    ← ハッシュでコミットを指す
       │
       ▼
.git/objects/f1/e2d3c...           ← コミットオブジェクト
   tree → ...
   parent → ...                    ← 親コミットへ続く
       │
       ▼
.git/objects/ab/cd1234...          ← tree オブジェクト
   "hello.txt" → blob ce0136...
       │
       ▼
.git/objects/ce/0136...            ← blob オブジェクト (ファイル内容)

このステップのまとめ

  • ブランチ = .git/refs/heads/<名前> という1行ファイル
  • HEAD = .git/HEAD ファイル。ブランチを文字列で指す
  • 軽量タグ = .git/refs/tags/<名前> という1行ファイル
  • これらは すべてただのテキスト。だから軽い・速い
